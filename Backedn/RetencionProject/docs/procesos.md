# Mapa de procesos de Retención

El flujo de retención abarca las actividades relacionadas con la evaluación de riesgos y la seguridad del empleado que se va a retener.

1. **Solicitud de revisión**: el área de RRHH indica un caso para revisar la retención de un empleado.
2. **Evaluación inicial**: se recopilan datos del empleado y contexto laboral.
3. **Identificación de riesgos**: se determinan posibles riesgos asociados al puesto o situación.
4. **Propuesta de medidas**: se sugieren acciones preventivas o correctivas.
5. **Aprobación**: líder de retención revisa y aprueba el plan.
6. **Seguimiento**: se monitorean los resultados y se actualiza el registro.

> El proceso es colaborativo; otros equipos (reclutamiento, nómina, salud) aportan insumos.
