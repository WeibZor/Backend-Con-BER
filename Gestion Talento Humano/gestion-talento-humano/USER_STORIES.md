# Historias de Usuario

1. **Registro de aspirante**
   - *Como* reclutador
   - *Quiero* poder registrar nuevos aspirantes con datos personales y puesto deseado
   - *Para* centralizar la información y facilitar procesos de selección.

2. **Seguimiento de selección**
   - *Como* gerente de selección
   - *Quiero* actualizar y consultar el estado de evaluación de cada aspirante
   - *Para* decidir quiénes pasan a entrevistas o son descartados.

3. **Contratación**
   - *Como* analista de RH
   - *Quiero* transformar aspirantes aprobados en empleados del sistema
   - *Para* iniciar sus registros en nómina, formación y otros procesos.

4. **Generación de nómina**
   - *Como* responsable de nómina
   - *Quiero* calcular y almacenar el salario de un empleado para un período dado
   - *Para* disponer de datos para pagos y reportes.

5. **Registro de formación**
   - *Como* coordinador de capacitación
   - *Quiero* asignar cursos y registrar competencias adquiridas por empleado
   - *Para* llevar control de desarrollo y necesidades de formación.

6. **Evaluación del desempeño**
   - *Como* supervisor
   - *Quiero* registrar una puntuación y observaciones sobre el desempeño de un empleado
   - *Para* hacer seguimientos y tomar decisiones de promoción o mejora.

7. **Control de retención (SST)**
   - *Como* jefe de SST
   - *Quiero* documentar riesgos e intervenciones asociadas a un empleado
   - *Para* cumplir normativas y reducir incidentes.

8. **Historias frontend**
   - *Como* usuario del sistema (reclutador, gerente, empleado), quiero interfaces web donde:
     * ingresar datos de aspirantes y empleados,
     * ver reportes de estado de procesos,
     * actualizar información de nómina, formación, evaluaciones y riesgos.
