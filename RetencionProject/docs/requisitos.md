# Requerimientos

## Requerimientos funcionales

1. **Registrar retención**: permitir crear un registro de retención vinculado a un empleado.
2. **Actualizar información**: modificar el estado, riesgos o medidas de un registro existente.
3. **Consultar historial**: listar todas las retenciones de un empleado o rango de fechas.
4. **Generar reportes**: exportar datos de retenciones para análisis.
5. **Notificaciones**: avisar al responsable cuando una revisión esté próxima.

## Requerimientos no funcionales

- **Seguridad**: solo usuarios autorizados pueden acceder y modificar registros.
- **Disponibilidad**: el servicio debe estar disponible 99.5% del tiempo.
- **Rendimiento**: la consulta de historial debe devolver resultados en menos de 1 segundo.
- **Mantenibilidad**: código modular con pruebas unitarias.
- **Portabilidad**: ejecutar en Linux o Windows sin cambios.
